# AppInfoDesktopPlugin

The AppInfoDesktopPlugin provides a comprehensive view of application information, organized by scope and easily searchable. It displays key-value pairs of application data in a clean, grid-based interface with built-in search and copy functionality.


## Features

### 1. Organized Information Display
- **Scope-Based Organization**: Information grouped by logical scopes
- **Grid Layout**: Clean, adaptive grid display (400-800px columns)
- **Entry Counting**: Shows number of items per scope
- **Visual Hierarchy**: Clear section headers and content separation

### 2. Interactive Features
- **Quick Copy**: One-click copying of any value
- **Search Functionality**: Real-time filtering of entries
- **Responsive Design**: Adapts to different window sizes

### 3. Entry Management
Each entry includes:
- **Scope**: Logical grouping of related information
- **Key**: Property identifier
- **Value**: Property value
- **Copy Button**: Easy value copying

### 4. Search Capabilities
- **Real-time Filtering**: Instant results as you type
- **Case-Insensitive**: Search matches regardless of case
- **Multi-field Search**: Matches in both keys and values
- **Deep Linking**: Direct access via search URLs

### 5. Special Integrations
- **Clipboard Integration**: One-click copying of tokens and values for use in other tools

## Usage

### Basic Navigation
1. Connect to your application
2. Browse information organized by scope
3. Use the search bar to find specific entries
4. Click copy buttons to capture values

### Search Tips
- Search by key or value
- Results update in real-time
- Clear search to see all entries
- Use deep links for direct access

### Deep Link Support
Access specific searches using:
```
echo://plugin/appinfo/search?query=YourSearchTerm
```

### Working with Entries
- Copy values with one click
- View entry counts per section
- Browse by scope for organized access
